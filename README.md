# YTTVPremium

App de YouTube para TV (Android TV / Google TV / TV box) sin anuncios, con SponsorBlock y control de velocidad.
Se abre con un código de acceso: los mismos códigos de **YTPremium** sirven aquí (servicio `ytpremium`),
y cada TV ocupa uno de los dispositivos del código.

## Descargar

- **Recomendado (casi todos los TV):** https://github.com/ByronR199716/YTENTV/releases/latest/download/YTTVPremium-armeabi-v7a.apk
- Solo equipos de 64 bits: https://github.com/ByronR199716/YTENTV/releases/latest/download/YTTVPremium-arm64-v8a.apk

## Cómo se arma

Todo lo propio de YTTVPremium está en la carpeta [`yttvpremium/`](yttvpremium/README.md).
El resto del repositorio es el código de Cobalt / TizenTube Cobalt tal como viene del proyecto original.
